# OWRTPsiphon

[English](README.md) | [Русский](README_RU.md)

**OWRTPsiphon** — это лёгкий веб-интерфейс LuCI для OpenWrt, который управляет туннелем Psiphon на базе `bepass-org/warp-plus` (режим `--cfon`) и предоставляет постоянный локальный SOCKS5-прокси.

## Что такое Psiphon?

Psiphon — это **инструмент обхода цензуры**, а не классический VPN. Он использует комбинацию технологий шифрования и обфускации, чтобы помочь пользователям получать доступ к заблокированному контенту. Ключевые отличия от VPN:
- **Назначение:** Обход интернет-блокировок, а не гарантированная анонимность.
- **Архитектура:** Сеть прокси-серверов с различными протоколами (SSH, VPN, HTTP-прокси), которые могут автоматически переключаться для обхода блокировок.
- **Ограничения:** Бесплатные серверы Psiphon могут быть медленнее и не предназначены для задач, критичных к приватности. Они не гарантируют анонимность.

**OWRTPsiphon** — это всего лишь контроллер, который управляет движком `warp-plus` на OpenWrt. Это **не** VPN-сервис, и автор этого проекта **не является** создателем Psiphon, Cloudflare или `warp-plus`.

## Возможности

* **Самостоятельный SOCKS5-прокси:** Это независимая служба. Вы можете использовать `socks5://192.168.1.1:8086` в любых приложениях в вашей локальной сети.
* **Идеально для Steer и Zapret-Manager:** Постоянный адрес `socks5://192.168.1.1:8086#OWRTPsiphon`, который не меняется при переключении стран.
* **Интеграция с Zapret-Manager:** Поддерживает установку без LuCI (`--no-luci`). Бэкенд управляется через `ubus call owrt-psiphon ...`, что позволяет ZM отрисовывать свой интерфейс.
* **Безопасность конфигурации:** Не изменяет настройки Steer, Zapret, firewall/nftables, PPPoE, Wi-Fi и маршрутизацию.
* **Автоматизация и Watchdog:** Автостарт при загрузке и проверки (каждые 1/6/12/24 часа) с переключением на рабочий узел с наименьшим пингом.

## Установка

Выполните команду SSH на вашем роутере:

Используя `curl`:

    curl -fsSL "https://raw.githubusercontent.com/Tan4ig/owrt-psiphon/main/install.sh" -o /tmp/owrt-install.sh && sh /tmp/owrt-install.sh

После установки откройте **Службы → OWRTPsiphon** в LuCI. Вставьте `socks5://192.168.1.1:8086#OWRTPsiphon` в **Steer → VPN → Свои серверы**.
