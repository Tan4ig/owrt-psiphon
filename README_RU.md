# OWRTPsiphon

[English](README.md) | [Русский](README_RU.md)

**OWRTPsiphon** — это лёгкий веб-интерфейс LuCI для OpenWrt, который управляет туннелем Psiphon на базе `bepass-org/warp-plus` (режим `--cfon`) и предоставляет постоянный локальный SOCKS5-прокси.

## Возможности

* **Самостоятельный SOCKS5-прокси:** Это независимая служба. Вы можете использовать `socks5://192.168.1.1:8086` в любых приложениях в вашей локальной сети.
* **Идеально для Steer:** Постоянный адрес `socks5://192.168.1.1:8086#OWRTPsiphon`, который не меняется при переключении стран.
* **Безопасность конфигурации:** Не изменяет настройки Steer, Zapret, firewall/nftables, PPPoE, Wi-Fi и маршрутизацию.
* **Компактная панель LuCI:** Статус в реальном времени, внешний IP, сортировка стран по пингу, автоподбор и проверка обновлений (самой программы и движка) в один клик.
* **Автоматизация и переход на лучший узел:** Автостарт при загрузке и проверки работоспособности (каждые 1/6/12/24 часа) с переключением на рабочий узел с наименьшим пингом.

## Установка

Выполните одну из команд по SSH на вашем роутере:

Используя `curl`:

    curl -fsSL "https://raw.githubusercontent.com/Tan4ig/owrt-psiphon/main/install.sh" -o /tmp/owrt-install.sh && sh /tmp/owrt-install.sh

Используя `wget` (если `curl` не установлен):

    wget -O /tmp/owrt-install.sh "https://raw.githubusercontent.com/Tan4ig/owrt-psiphon/main/install.sh" && sh /tmp/owrt-install.sh

После установки откройте **Службы → OWRTPsiphon** в LuCI. 
Чтобы использовать в **Steer**, вставьте `socks5://192.168.1.1:8086#OWRTPsiphon` в **Steer → VPN → Свои серверы (или Подписка)**.
